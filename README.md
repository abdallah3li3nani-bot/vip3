# منصّة المعلّم — نظام إدارة الدروس والمذكرات والطلاب (Offline PWA)

تطبيق ويب تقدمي (**Progressive Web App - PWA**) يعمل **محلياً بالكامل (Offline-First 100%)** على الهواتف الذكية وأجهزة الكمبيوتر بدون الحاجة إلى أي اتصال بالإنترنت أو خوادم خارجية أو قواعد بيانات سحابية.

عربي بالكامل · تصميم متجاوب فائق السرعة · حماية دائمة للبيانات · تثبيت كـ تطبيق أصلي على الهاتف (Add to Home Screen).

---

## 🚀 المميزات والوظائف الرئيسية

### 1. تطبيق أوفلاين كامل (Offline-First 100%)
* **لا حاجة للإنترنت:** بمجرد فتح الرابط مرة واحدة وتثبيت التطبيق على الهاتف، يعمل للأبد بدون إنترنت.
* **قاعدة بيانات محلية متطورة (IndexedDB):** تخزين آمن وسريع جداً يتحمل آلاف الطلاب والحصص والمذكرات بدون أي بطء.
* **صفر تكلفة وصفر اشتراكات:** لا يتطلب Supabase أو سيرفرات مدفوعة.

### 2. قفل التطبيق بكلمة مرور (App Lock)
* قفل التطبيق بشاشة أمان أنيقة برمز مرور أو كلمة سر خاصة بالمعلم فقط.
* إمكانية تغيير كلمة المرور بسهولة في أي وقت من الإعدادات.
* كلمة المرور الافتراضية: `1234`.

### 3. دليل طلاب المدرسة وحصر المشتركين بالدروس
* **حصر شامل لطلاب الفصول:** تسجيل جميع طلاب المدرسة الذين يدرس لهم المعلم.
* **تصنيف ذكي:**
  * **المشتركون بالدروس:** الطلاب المقيدون في مواد دراسية خاصة.
  * **غير المشتركين (طلاب المدرسة فقط):** للرجوع إليهم أو تسجيلهم فور اشتراكهم.
* **بيانات مبسطة:** التركيز على **اسم الطالب** و **الصف الدراسي** و **التخصص** بدون الحاجة لرقم هاتف إجباري.
* **تسجيل سريع للمواد:** البحث عن الطالب واختياره مباشرة لتسجيل المواد بدون إعادة كتابة بياناته.

### 4. استيراد كشف الطلاب من ملف إكسيل (Excel Import)
* رفع شيت إكسيل بصيغة `.xlsx` أو `.xls` أو `.csv` يحتوي على عمودين فقط: **اسم الطالب** و **التخصص**.
* قراءة الملف محلياً بالكامل داخل المتصفح واستيراد مئات الطلاب دفعة واحدة في ثوانٍ معدودة.
* توفير زر لتحميل نموذج إكسيل جاهز وفارغ للتعبئة المباشرة.

### 5. حزم الأسعار الشهرية والخصومات الذكية للمواد
* **الصف الأول الثانوي (مادتان كحد أقصى):**
  * تحديد سعر المادة الواحدة وسعر المادتين معاً (عرض حزمة بخصم شهري تلقائي).
* **الصف الثاني الثانوي (4 مواد كحد أقصى):**
  * جدول أسعار مرن حسب عدد المواد المختارة: (1 مادة = X، 2 مادتين = Y، 3 مواد = Z، 4 مواد = W).
* احتساب الاشتراك الشهري والخصم تلقائياً عند تسجيل مواد الطالب مع إمكانية تعديل السعر يدوياً لأي طالب.

### 6. قسم المذكرات والملازم الدراسية (Booklets Management)
* **كتالوج المذكرات:** إضافة مذكرات لكل صف دراسي مع تحديد سعر البيع والترم.
* **حجز ودفع مرن:**
  * البحث عن الطالب واختيار المذكرة.
  * تسجيل المدفوع وحساب المتبقي تلقائياً (دين على الطالب).
  * تحديد طريقة الدفع بدقة: **كاش نقدي** / **محفظة إلكترونية (فودافون كاش وغيرها)** / **انستاباي (InstaPay)**.
* **إدارة التسليم الفعلي:** زر تفاعلي بنقرة واحدة (تم التسليم / لم يستلم بعد).
* **تقارير وفلاتر المذكرات:**
  * فلتر: **من لم يستلم المذكرة بعد** (لمعرفة عدد النسخ المطلوب طباعتها وتجهيزها).
  * فلتر: **استلم وعليه متبقي** (حصر الديون والفلوس المتبقية على الطلاب).
  * فلتر: **المستلمون والمسددون بالكامل**.
  * إحصائيات مالية إجمالية لمبيعات المذكرات ومفصلة بوسيلة الدفع.

### 7. نظام النسخ الاحتياطي وحماية التخزين (Backup & Persistence)
* **التخزين الدائم (Storage Persistence):** تفعيل حماية المتصفح الرسمية لمنع نظام الهاتف من حذف بيانات التطبيق عند تنظيف الذاكرة المؤقتة.
* **نسخ يومي تلقائي (Rolling 5 Snapshots):** يقوم التطبيق تلقائياً عند فتحه بأخذ لقطة يومية كاملة ويحتفظ بآخر 5 نسخ فقط، ويحذف الأقدم تلقائياً.
* **حفظ في مجلد بالهاتف:** إمكانية اختيار مجلد على الهاتف لحفظ ملفات النسخ الاحتياطية.
* **تصدير واستعادة ملفات JSON:** تنزيل نسخة احتياطية واستعادتها في أي وقت بنقرة واحدة.
* **مشاركة النسخة الاحتياطية:** إرسال ملف النسخة لنفسك على الواتساب أو Google Drive.

## 🛠️ التشغيل والرفع على GitHub Pages

### التشغيل المحلي للتطوير:
```bash
npm install
npm run dev
```

### البناء والرفع على GitHub Pages:
1. بناء المشروع لإنتاج مجلد `dist`:
```bash
npm run build
```
2. رفع محتويات المشروع على مستودع GitHub الخاص بك.
3. من إعدادات المستودع على GitHub:
   * اذهب إلى **Settings** ← **Pages**.
   * اختر الـ Branch (مثلاً `gh-pages` أو `main` مع تحديد مجلد `/dist` أو تفعيل GitHub Actions لبناء Vite تلقائياً).
4. افتح رابط GitHub Pages على هاتفك، ثم اضغط على خيارات المتصفح واختَر **"إضافة إلى الشاشة الرئيسية" (Add to Home Screen)**.
5. سيعمل التطبيق كبرنامج أصلي على هاتفك بأعلى سرعة وبدون إنترنت نهائياً!
